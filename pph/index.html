A local tool for laying out images onto A4 sheets before printing. Runs entirely in this browser tab — nothing leaves your laptop.

Two portrait images, placed side by side as two A5 halves on one A4 landscape sheet. Each image fills its half edge to edge — no wasted margin.

Four portrait images, arranged 2×2. Each one is sized to exactly a quarter of an A4 sheet — that's A6, the same proportions as A5 — so the whole page is used and nothing is wasted.

Any number of images, any sizes. Set a print width for each and it packs them onto A4 sheet(s) with dashed cut lines, using as many sheets as needed.
